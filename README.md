## نظرة عامة

**Trainix** منصة رقمية متكاملة لإدارة التدريب الميداني، تربط الطالب بالجامعة والشركة والمدرب على نظام واحد — من لحظة البحث عن فرصة تدريب وحتى استلام التقرير النهائي والشهادة. جوهر المنصة محرك مطابقة يعمل بالذكاء الاصطناعي يقارن مهارات كل طالب تلقائيًا مع متطلبات فرص التدريب المتاحة، بدل الاعتماد على البحث اليدوي والتنسيق عبر الإيميل.

---

## المميزات

### 🤖 مطابقة ذكية بالذكاء الاصطناعي
تصنيف تلقائي لمهارات الطالب ضمن ثماني فئات تقنية (Frontend، Backend، Database، DevOps، AI Engineer، QA/Testing، Mobile، Tools)، ومقارنتها بمتطلبات كل فرصة تدريب لحساب نسبة تطابق دقيقة تأخذ بعين الاعتبار المعدل التراكمي ونمط العمل المفضّل أيضًا.

### 📄 تحليل السيرة الذاتية بالذكاء الاصطناعي
رفع سيرة ذاتية (PDF/DOC/DOCX) وتحليلها تلقائيًا عبر خدمة مستقلة تستخدم نموذجًا لغويًا (Groq) لاستخراج المهارات، التعليم، الخبرات، وبيانات التواصل بشكل منظّم.

### 📝 بناء سيرة ذاتية من الموقع
الطلاب اللي ما عندهم CV جاهز يقدروا يعبّوا فورم ببياناتهم (تعليم، مهارات، خبرات)، والنظام يصمم لهم سيرة ذاتية احترافية بصيغة PDF تلقائيًا، وتمر مباشرة بنفس محرك التحليل والمطابقة.

### 💬 دردشة فورية ومكالمات فيديو
تواصل مباشر بين الطالب والجامعة والمدرب عبر دردشة لحظية (Supabase Realtime)، ومكالمات فيديو حقيقية للمقابلات والمتابعة (ZegoCloud).

### 📊 خطط تدريب وتقارير أسبوعية
الشركة أو المدرب ينشئ خطة تدريب أسبوعية بمهام محددة، والطالب يرفع تقارير أسبوعية تعتمدها الجامعة، وصولًا لتقرير نهائي بتقييمات مفصّلة.

### 🔔 إشعارات ذكية ومهام مجدولة
إشعارات فورية لكل الأحداث المهمة (تقديم، قبول، رفض، مواعيد تسليم)، بالإضافة لمهام تعمل تلقائيًا بجدولة زمنية: تذكير أسبوعي بالتقارير، تذكير قبل 24 ساعة من المواعيد النهائية، وتنظيف دوري للإشعارات القديمة.

### 📈 لوحات تحكم تفاعلية
لوحة تحكم مخصصة لكل دور (طالب، شركة، جامعة، مدرب، مدير) بإحصائيات ورسوم بيانية حية.

### 📱 تطبيق موبايل
تطبيق React Native يغطي نفس الميزات الأساسية للوصول من الهاتف المحمول.

## من يستخدم المنصة

| الدور | الصلاحيات الرئيسية |
|---|---|
| 🎓 **الطالب** | بناء الملف الشخصي، رفع/بناء CV، تصفح الفرص المطابقة، التقديم، متابعة خطة التدريب والتقارير |
| 🏢 **الشركة** | نشر فرص التدريب، مراجعة المتقدمين وقبولهم/رفضهم، إنشاء خطط تدريب، تعيين مدربين |
| 🏫 **الجامعة** | متابعة طلابها، اعتماد التقارير الأسبوعية والنهائية، الموافقة على شراكات الشركات |
| 👨‍🏫 **المدرب** | الإشراف على الطلاب المعينين، مراجعة تقدمهم وتقاريرهم |
| 🛡️ **المدير** | إدارة المستخدمين، اعتماد الشركات والجامعات الجديدة، إحصائيات شاملة للنظام |

## البنية التقنية

| الطبقة | التقنيات |
|---|---|
| **Backend** | Node.js، Express، MySQL (mysql2)، Socket.io، Bcrypt، Multer، node-cron |
| **Frontend** | React، React Router، Recharts، Socket.io Client |
| **خدمة الذكاء الاصطناعي** | Python (Flask) + Groq API لتحليل السير الذاتية وتوليدها |
| **الموبايل** | React Native + TypeScript |
| **التواصل الفوري** | Supabase Realtime (دردشة)، ZegoCloud (فيديو) |
| **قاعدة البيانات** | MySQL |

## التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- MySQL 8+
- Python 3.10+ (لخدمة تحليل السير الذاتية)

### 1. قاعدة البيانات
```bash
mysql -u root -p < database_schema.sql
```

### 2. الخادم (Backend)
```bash
cd backend
npm install
cp .env.example .env   # عدّل القيم حسب بيئتك (بيانات MySQL، مفتاح Groq)
npm start
```
يعمل على `http://localhost:5050`

### 3. الواجهة (Frontend)
```bash
cd frontend
npm install
npm start
```
يعمل على `http://localhost:3000`

### 4. خدمة الذكاء الاصطناعي
```bash
cd ai_service
pip install -r requirements.txt
python cv_analyzer.py
```
يعمل على `http://localhost:5001`
